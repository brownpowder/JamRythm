# Rhythm & Chords — MVP仕様

最終更新: 2026-08-25

## コンセプト

**「ポケットに入る専属リズム隊。コード感覚を養う、新感覚の伴奏＆作曲ツール」**

本アプリは、ドラムとベースの「リズム隊」を自動生成してループ再生する伴奏アプリである。
AIが完成された曲を提示するのではなく、リズム隊が強固な「土台」を作り、ユーザー自身がギターやピアノで上物（コードやメロディ）を乗せることで、音楽的な対話を生み出すことを目的とする。

**コア・コンセプト:**
- **上物（ギター・ピアノ等）は鳴らさない**: アプリはあくまで伴奏に徹し、演奏の主役はユーザー自身。
- **ベースラインはループ中固定**: 土台が変わらないからこそ、同じベース音に対して「どんなコードを乗せるとどう響くか」を安全に試行錯誤できる。

## 想定するユースケース

1. **手軽なジャムセッション（伴奏）**: バンドメンバーがいなくても、いつでもどこでもリズム隊に合わせて楽器の練習やソロのアドリブ練習ができる。
2. **コード感覚の育成**: ベース音に対して「安定」「切ない」「おしゃれ」といったラベル付けされたコード候補を試すことで、音楽理論やボイシングの感覚を耳と手で養う。
3. **作曲・スケッチツール**: 提供されたコード進行のアイデアからインスピレーションを得て、自分の曲のAメロやサビの骨格を組み立てる。

## コア体験

1. キー、テンポ、ジャンル／ムードを選ぶ。
2. アプリがドラム、ベース、曲の基本構成を生成する。
3. 再生位置に合わせ、現在のコードと次のコードを表示する。
4. 各小節で、ドラムとベースに合うコード候補を3〜4個表示する。
5. ユーザーが候補を選ぶ、または実際にギター／ピアノを弾いて試す。
6. 気に入った進行を保存し、Aメロ、Bメロ、サビへ並べる。

## ターゲットプラットフォーム

- **iOS / iPadOS 専用**
  - 楽器を弾きながら譜面台等に置いて操作するユースケースを想定し、モバイル・タブレット端末に特化する。
  - Macネイティブ版（Mac Catalyst等）の開発は行わず、リソースをiOSのUI/UXに集中させる（Apple Silicon Macでの互換動作には任せる）。

## MVP機能

### リズム隊と再生

- DrumとBassを自動生成して再生する。
- テンポ変更、再生／停止、指定小節のループに対応する。
- まずは8小節、必要に応じて16小節のループを扱う。
- Drum／Bassは自作SoundFont（SF2）を音源として利用する。

### 曲構成

- セクション: Intro / A / B / Chorus / Bridge / Outro
- MVPではA・B・Chorusを中心に、セクションを並べ替えられるようにする。
- 生成は、ジャンル別テンプレートとルールベースのランダム化で行う。
- AIや外部APIは使用しない。生成は端末内で完結させる。

### コード候補

各小節では、現在のキー、スケール、Bass音、前後のコードを基に3〜4候補を表示する。

候補は音楽的な役割をラベルとして見せる。

| 表示ラベル | 例: C MajorでBassがGの場合 | ねらい |
|---|---|---|
| 安定 | G | 基本の和音。進行を分かりやすく保つ。 |
| 少し切ない | Em7 | 相対短調や6度を使い、やわらかな陰りを加える。 |
| おしゃれ | G7 / G13 / Dm9 | 7th、テンション、色彩的な和音を加える。 |
| 緊張感 | D♭7 → C / Bdim | 代理コードや減七で解決感を作る。 |

表示内容（UI要素）:

- 現在のコード / 次のコード
- 小節番号と拍の進行表示
- 選択可能なコード候補リスト
- 選択済みコードの進行タイムライン
- **[Pro Unlock] 譜面ビュー（五線譜 / ギターTAB譜）**:
  - 外部ライブラリに依存せず、SwiftUIの `Canvas` を用いたネイティブ描画で実装（完全オフライン動作・軽量化）。
  - 現在のコードの構成音や具体的なボイシングを視覚的に表示する。

## 生成ロジックとデータ構造（ハイブリッド方式）

完全な自動生成による音楽的破綻を防ぐため、**「土台となるベース進行はテンプレートから選び、コード候補は動的に理論計算する」ハイブリッド方式**を採用する。

### 1. データ構造（ドメインモデル）

- **`ProgressionTemplate` (マスターデータ / 王道進行リスト)**
  - データベースや外部JSONは使わず、**Swiftの構造体（Struct）として配列でハードコード**し、読み込み速度と型安全性を最優先する。
  - キーに依存しないよう、ディグリーネーム（度数）で定義する（例: `[4, 5, 3, 6]`, `[1, 6, 2, 5]`）。
- **ユーザーデータ（保存プロジェクト）**
  - ユーザーが作成したプロジェクトや進行データは、ローカル（JSON形式やUserDefaults等）に保存し、マスターデータと明確に分離する。
- **`Project` -> `Section` -> `Measure` (小節)**
  - `Measure` には以下の情報を持たせる。
    - `baseDegree`: 土台として選ばれた度数（例: 4）
    - `bassNote`: 現在のキーから決定された実際のベースルート音
    - `chordCandidates`: 算出されたコード候補（配列）
    - `selectedChord`: ユーザーが最終的に選んだコード

### 2. 生成フロー

1. **ベースラインの生成 (Template)**
   - ユーザーがKeyを選択して生成ボタンを押すと、バックグラウンドで `ProgressionTemplate` からセクションに合う進行が選ばれる。
   - 選ばれたディグリーネームとKeyを元にベースのルート音が決定され、そこからベースライン（MIDI）が生成される。
2. **コード候補の算出 (Auto計算)**
   - 決定したベースルート音を基準に、4つのラベルに対するコード候補をルールベースで算出する。
   - `Ikatomape-midigene` の理論モデルを活用し、音楽的な文脈を付与する。

### 3. 候補算出ルールの具体例（例: Key = C, Base = G の場合）

- **安定 (Stable)**
  - 基本のダイアトニックトライアド、またはシンプルな7thコード。
  - 算出例: `G`, `G7`
- **少し切ない (Melancholy)**
  - サブドミナントマイナー、分数コード、平行調の要素を含むもの。
  - 算出例: `Em7/G`, `Fm6/G`
- **おしゃれ (Color/Stylish)**
  - テンション（9th, 11th, 13th）を含む和音、ツーファイブの分割など。
  - 算出例: `G13`, `Dm9/G`
- **緊張感 (Tension)**
  - 代理コード、ディミニッシュ、裏コードなど、強い解決感や意外性を生む和音。
  - 算出例: `Db7/G`, `Gdim7`

セクションごとにコードの密度と提示する候補の重み付けを変える。（Aメロは安定中心、Bメロはおしゃれ優先など）

## 音源とマスタリング（音響）方針

- **SF2音源の活用**: 軽量なMono / 22.05 kHzのSampleを基本とし、Drum Kit、Bassを中心に読み込む（必要に応じて基本波形等も活用）。
- **スマホスピーカー対策（音圧と倍音）**:
  - アコギや生ピアノの生音に負けないよう、`AVAudioEngine` の出力段（マスターバス）にコンプレッサー/リミッターを強めにかけ、全体の音圧（ラウドネス）を最大限稼ぐ。
  - スマホスピーカーでは低音（100Hz以下）が聴こえにくいため、ベース音色には意図的に中音域の倍音成分（サチュレーション/薄いオーバードライブ）を付加し、存在感を持たせる。
- cymbal等のOne-shotは、SF2再生の差を考慮し、アプリ側でNote Offの扱いを補う余地を残す。

## UX・設定要件（レイテンシ対策）

- **オンボーディング案内**: アプリ初回起動時に、「生楽器と合わせる際は、イヤホン（片耳外し）や外部スピーカーの使用を推奨」するTipsを表示する。
- **Bluetooth遅延補正（設定項目）**: 無線イヤホンやBluetoothスピーカーを使用した際、「画面上のコード進行」と「実際に鳴っている音」にズレ（レイテンシ）が生じる問題に対応するため、UIの描画タイミングを意図的に遅らせて音と同期させる「オフセット調整機能」を設ける。

## マネタイズ

広告は表示しない。

買い切り型のIAPを基本にする。

### 無料版

- Drum／Bassの再生
- 基本のキー、テンポ、ジャンル
- 8小節の基本ループ
- コード候補: 「安定」「少し切ない」
- コード表示と演奏練習
- 少数のプロジェクト保存

### Pro Unlock（買い切り）

- コード候補: 「おしゃれ」「緊張感」
- 7th、テンション、代理コード、借用和音、簡単な転調
- 16〜64小節、A / B / Chorus / Bridgeを含む曲構成
- **1画面全体コード譜（俯瞰）ビュー**: リードシートのように曲全体のコード進行を1画面で確認でき、譜面台での演奏時にスクロールなしで俯瞰できる機能。
- プロジェクトの無制限保存・複製
- MIDI／Audio書き出し
- SoundFontの読み込み・差し替え
- 高度なコード難易度: Basic / Color / Advanced

### 将来の追加コンテンツ

- Genre Pack: Lo-fi、Pop、Rock、808 Hip-hop、House、Chiptune
- Sound Pack: 808 Kit、Keys、Chiptune、World Pluck
- Practice Pack: コードフォーム、段階的テンポ練習、セクションループ

これらも広告や消費型アイテムではなく、買い切りの追加コンテンツとして扱う。

## MVPでは扱わないもの

- クラウドAIによる曲生成
- サブスクリプション
- 広告
- 本格的なDAW編集
- SNS機能や共同編集

## 最初に作る順序

1. SF2を鳴らせる再生エンジンと、Drum／Bassのループ再生。
2. Keyとテンポの選択、8小節のルールベース生成。
3. 再生位置と連動するコード表示。
4. 各小節の3〜4候補提示と、進行への反映。
5. 保存、曲構成、Pro Unlockの実装。
